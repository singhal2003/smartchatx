# SmartChatX

**SmartChatX** is a real-time chat application with AI-powered features like chat summarization, multilingual translation, and toxic message detection. Inspired by platforms like WhatsApp and Discord, it supports private/group chats, typing indicators, and media sharing — built for modern, intelligent communication.

> ⚠️ This project is currently under development and will be updated continuously.

## 🚀 Features

- 🔐 User authentication (JWT)
- 💬 One-to-one and group messaging
- ✏️ Typing indicators and online status
- 📎 Media sharing (images, files)
- 🧠 AI-powered chat summarization (OpenAI)
- 🌐 Real-time message translation
- ⚠️ Toxic content detection

## 📦 Tech Stack

- **Frontend:** ReactJS, TailwindCSS, Socket.IO-client
- **Backend:** Node.js, Express.js, Socket.IO
- **Database:** MongoDB (Atlas)
- **Authentication:** JWT
- **AI/NLP APIs:** OpenAI API, Google Translate API
- **Hosting:** Vercel (Frontend), Render (Backend)

## 🛠️ Setup Instructions

1. Clone the repo:  
   `git clone https://github.com/YourUsername/smartchatx`

2. Install dependencies:
   - `cd client && npm install`
   - `cd server && npm install`

3. Set up `.env` files for OpenAI keys and JWT

4. Run both client and server
